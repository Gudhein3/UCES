Absolute name |Symbolic name |Description/Function                 |Saved by
x0            |zero          |Always zero                          | -
x1            |pc            |Program counter                      | Callee
x2            |ra            |Return address                       | Caller/Callee
x3            |sp            |Stack pointer                        | Callee
x4            |fp            |Frame pointer                        | Callee
x5            |gv            |Global value                         | Caller
x6            |rv            |Return value                         | Callee
x7-x15        |a0-a8         |Arguments                            | Callee
x16-x31       |r0-r15        |General Purpose                      | Caller

Additional arguments should be pushed to the stack in order from first to last and shouldn't be poped by callee:
push argument1
push argument2
push argument3
call function
addsi sp -3*4 sp

Function body:
  push ra
  push fp
  mv sp fp
  ...
  mv fp sp
  pop fp
  pop ra
  mv ra pc

MMIO devices should use range from 0x7FE00000 to 0x7FFFFFFF (inclusively)
All address ranges bellow are inclusive.

UART  - 0x7FE00000 - 0x7FE00000
    0x7FE00000 - Console input & Console output
               - Implementation-dependent; Console output must be implemented for debugging purposes
DRIVE - 0x7FE00010 - 0x7FE000
