Assembly syntax
 What do symbols h, b, o before numbers mean?
  They're marking that the number is either hexadecimal(h), binary(b), octal(o), or decimal(d).
  By default all numeric literals are parsed as decimals.
  But if you want to denote it explicitly, you can place "d" before the numeric literal.
 How can I find a list of all registers?
  You can read "ABI.txt".
 How can I find a full list of all instructions?
  You can read "INSTS.txt".
 What pseudo instructions does assembly have?
  .db CONST - put 8 bits
  .dw CONST - put 16 bits
  .dd CONST - put 32 bits
  .org CONST - Change a current address of generating symbols table
  .ld CONST REGISTER - Loads a 32 bit integer into a register(Doesn't work with pc for obvious reasons)
  .if REGA COND REGB REGX REGY - Iff `REGA COND REGB`, copies data from regx to regy, otherwise does nothing;
                                 Overwrites t0 btw.
                                 Condition may be one of those:
                                   `o*`     - does REGA*REGB cause overflow
                                   `c+`     - does REGA+REGB return carry
                                   `c-`     - does REGA-REGB return carry
                                   `>u`     - is REGA unsigned above than REGB
                                   `<u`     - is REGA unsigned below than REGB
                                   `>s`     - is REGA signed greater than REGB
                                   `<s`     - is REGA signed smaller than REGB
                                   `!=`     - is REGA not equal to REGB
                                   `==`/`=` - is REGA signed smaller than REGB

Architecture
 Is it based on RISC, CISC, or MISC?
  Kinda on RISC.

Misc
 What does UCES processor know about MMIO?
  Nothing, MMIO devices mapped by memory controller.
  So the processor calls the memory controller to write into memory, and the controller decides which memory device to call.
